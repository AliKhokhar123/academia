04 + 05 + 06 · QUIZ UXOne question per screen. QSM supports pagination natively (Options → Pagination), so this is the reliable route: one question per page with the theme's own markup restyled — no fork of the plugin, questions and scoring logic untouched. If per-question pagination proves unstable on this install, the fallback is 5 per page (8 steps) with the same visual treatment. Progress label and bar are custom markup bound to QSM's page state. Answer rows are 100% clickable with hover and selected states; the real questions above come from the live test.

Primary = Academia orange, used only for the single most important action per section. Secondary = white with border. Text link = tertiary. Hover, focus-visible and active states defined once and inherited by Elementor and QSM buttons alike.

11 + 12 + 13 · SYSTEM, BUTTONS, SPACINGQSM's stylesheet is the main offender today — it ships its own font sizes and button styles that clash with the Elementor kit. Approach: one scoped stylesheet on this page that maps QSM's classes onto the tokens above, plus an 8px spacing scale (8 / 16 / 24 / 32 / 48 / 64 / 96) for section rhythm. No extra plugin, no theme fork.
